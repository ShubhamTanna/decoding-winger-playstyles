# Explorer copy audit for Claude

**Reviewed:** [portfolio `explorer` commit 46386e1](https://github.com/ShubhamTanna/shubhamtanna-site/tree/46386e142f47766ae413cb5f883755130054e6fc). This is a read-only review of source strings, selection/formatting helpers, data derivation and page call sites at that revision. It is not a rendered-site or browser acceptance test. Findings refer to that commit, not a future deployment. Use the [fact sheet](case_study_fact_sheet.md) and the [research wording rules](frontend_research_support.md) for the replacements.

**Verdict:** The explorer generally uses the right quantities. It distinguishes player feature percentiles from cluster-centre z-scores, uses all 20 features for distance, indexes profiles by club spell and warns that style is not quality. The main risks are prose that implies a tracked position, treats PCA proximity as a full-profile match, or calls a sensitivity-test result a boundary diagnosis. Fix the high-severity items before borrowing copy for the case study. Medium means a real risk of misreading; low means a precision or labelling improvement.

## What the 0.3 SD convention actually controls

[`src/lib/winger-format.ts:31–33,42–59`](https://github.com/ShubhamTanna/shubhamtanna-site/blob/46386e142f47766ae413cb5f883755130054e6fc/src/lib/winger-format.ts#L31-L59) always picks the six **largest absolute** centroid z-scores, breaking ties by original feature index. It splits by sign. On a side with **fewer than two** of the six, it can append **up to three additional** same-sign features outside the six, in magnitude order, if their *unrounded* magnitude is at least 0.3 SD. It does not force a balanced chart, filter the original six, or decide which sentences get written. Signature lines 46–49 and 95–100 mark the additions “for context.” The all-20 view is unfiltered. The featured example on `src/app/work/decoding-winger-playstyles/explore/page.tsx:11–17` deliberately uses only same-direction features from the six, not these extras.

Replaying the helper rule on the released centroids gives:

| Group | Extra context (strongest first) |
|---|---|
| C0 | Above: shots per 100 attacking-third touches; carry share of box entries; progressive reception share |
| C1 | None |
| C2 | Above: progressive passes per 90; progressive pass share; average shot distance |
| C3 | Below: long-pass share; average shot distance; progressive passes per 90 |
| C4 | Below: carry share of progression; progressive reception share |

**Keep as an editorial convention (low).** A 0.3 SD group-mean difference is on a common scale; it is not a significance test, an estimated minimum meaningful effect, a condition for assignment, or evidence a distinction is typical of every member. No positive trait is required for balance. Suggested note: “The six strongest differences always appear. When they mostly point one way, we also show up to three differences the other way, if the centre is at least 0.3 standard deviations from the overall mean. These are context, not defining traits.” For the all-20 view use “higher/lower values” instead of universally “does more/less”: longer shot distance is not more shooting. Prefer “six largest differences” to “six that define it” in `src/components/winger/StylesView.tsx`.
